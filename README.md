# GRAIN — Premium Ecommerce Front-End

Static three-page storefront for GRAIN.

## Pages
- `index.html` — Home
- `shop.html` — Shop
- `about.html` — About

## Included functionality
- Shared sticky transparent/translucent navigation
- Hamburger category menu
- Hero autoplay slider with previous/next controls and category-specific content
- Category navigation to Shop with URL category filters
- Product overview tabs: Featured / Top Rated / Best Sellers
- Search overlay + Shop inline search
- Shop category tabs
- Combinable price, category, and size filters
- Wishlist with `localStorage`
- Cart drawer with `localStorage`
- Product quick-view modal with image thumbnails, prev/next, fullscreen, quantity, size, color, wishlist, share, and add-to-cart
- Responsive layout for desktop/tablet/mobile
- Shared premium footer
- Floating WhatsApp contact button

## Notes
Images are loaded from Unsplash URLs so the site is ready to preview without a local image folder. Replace those image URLs with your own CDN/local assets for production.
Checkout is intentionally a front-end placeholder until a real payment/order backend is connected.
